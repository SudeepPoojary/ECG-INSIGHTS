# ECG-INSIGHTS


## Description
- Cardiovascular diseases (CVDs) encompass a range of conditions affecting the heart and blood vessels, including coronary artery disease, heart failure, and stroke. These diseases often arise due to factors such as high blood pressure, high cholesterol, smoking, diabetes, and obesity. They pose a significant global health burden, contributing to millions of deaths annually.


- Our machine-learning model shows promise in predicting cardiovascular diseases, including MI and arrhythmias, by analyzing electrocardiogram (ECG) charts


- The project aims to develop an intelligent ECG-pipeline app for Anganwadi workers, enabling real-time detection of cardiac issues via cell phones. The app provides instant alerts to empower workers and doctors to integrate cloud services for secure data storage and uses geolocation to identify nearby hospitals for timely referrals, enhancing cardiac healthcare access in low-resource areas.
